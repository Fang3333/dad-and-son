# 世界规则修改器

选一条现实规则，调四个参数，设三个世界假设，生成一条从原始到现代的分版长河。第 1 页设定，第 2–6 页一屏一章（原始 / 古代 / 近代早期 / 工业 / 现代），不滚动，点「下一版」翻；每版只摆被改写的大事，卡片左「原来」右「现在」对照，点卡片看细节。

在线体验：https://fang3333.github.io/dad-and-son/

情景推演，不是史实，也不是对真实未来的预测。

## 怎么玩

1. 第 1 页「设定」：选一条规则（取消大学考试 / 每天只工作四小时 / 商品不再有价格），拨四个参数开关，再设三个世界假设（技术会继续累积 / 资源足够 / 群体愿意合作）。点蓝色「生成这个世界 →」，进入第 1 版。
2. 第 2–6 页一屏一章、只读、不滚动：巨大空心版号 + 时代名 + 一句 headline + 「本版改写 N 件」。只摆被改写的大事（每章 2–4 件）：卡片左半「原来」灰纸斜线，右半「现在」纸色 + 深红右边，关键词深红，右上角「已改写」章。没改的不占位；整章没改够 2 件就显示「这一版没有改动」。
3. 点事件卡开浮层：60–100 字的细节 + 为什么 + 连锁反应；Esc 或点遮罩关闭。热点（亮哥的头发 / 猎鹰退休 / 不烧心）混在现代版，浮层带代号和「虚构」注记。
4. 底部「上一版 / 圆点 / 下一版」翻页，末版「下一版」变「回到第 1 版」；URL 是 #chapter/1…5，浏览器前进后退、键盘 ← → 都能翻；翻页 translateX 300ms，卡片错峰入场。顶栏世界线编号 + 第 N 版 / 5，点蓝色「修改假设」回第 1 页，选择原样保留，再次生成编号 +1 并回第 1 版。刷新不丢。
5. 假设不是装饰：关掉「资源足够」，免费世界的改写会整段落空，整章不够 2 件就空态直说；拨参数也会换讲法（比如允许黑市后，货币不是消失而是转进巷子）。

## 打开方式

- 双击 index.html 即可（file:// 直开）。
- 或任意静态服务器，例如 `npx serve` / `python -m http.server`。
- 断网可玩。无框架、无 CDN、无外部图片、无构建步骤。

## 三条诚实约定

- 长河是情景推演：每件大事的「现在」是按规则、参数、假设推出来的对照线，不是史实，也不是预测；卡上带「推算 / 假设 / 不确定」标签。
- 改写判定可追溯：每张卡的「为什么」一句话指回规则、参数或假设；假设关闭时改写落空，页面直说，不假装改写了。
- 热点只用代号、只写公开现象的虚构改写（亮哥 / 不烧心），每张带「虚构」章与「勿对号入座」注记，不写真实人物私生活。
