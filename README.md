# 时光胶囊 · 平行人生模拟器

> 三傻大赛作品。两个**零依赖、无后端、无 API key、双击即可离线玩**的网页：
> 输入一个两难选择，推演两条人生路线；还能改决定、生平行分支、导出成 PPT 素材。

## 两个玩法

| 页面 | 玩法 | 一句话 |
|---|---|---|
| `index.html` | **时光胶囊 · 平行人生模拟器** | 从高中/大学的一个两难问题出发，生成 A/B 两条人生路线；任意节点可「改决定」生平行分支，随机事件让每局不同 |
| `life.html` | **人生：无限分岔** | 从出生到死亡的文字人生模拟：随机家庭与性别、六显性属性、隐性变量、宿命三层、蝴蝶回响、八维结局与人生复盘 |

两页互相独立，顶栏可一键切换。

## 怎么运行

**双击 `index.html` 就能玩**；`life.html` 同样双击打开。不需要安装、不需要联网、不需要 API key。
要分享：把整个文件夹压缩发给对方，解压后双击 `index.html`。

## 核心功能

- 6 个预设人生剧本（选科 / 冲竞赛 / 艺考 / 重点班 / 住宿 / 情感），每个含 A/B 双路线 × 6 段人生
- **自定义问题**：没有你的问题就自己写一个，系统按关键词匹配最接近的剧本模板推演，结果页标明匹配了哪个模板
- 兴趣 / 目标 / 时间投入影响成功率与结局评分，AI 推荐会给出**为什么推荐**（目标权重、关键属性差、领先分差）
- 最多 6 条平行分支：任意节点「改决定」、粉色血缘虚线、分支删除、「随机人生」掷骰
- 20 个带时期区间的随机事件，每局抽 2 个；「换个运气」可重抽
- 本机保存与刷新恢复、JSON 导出、Canvas 手绘 PNG 导出（可直接贴进答辩 PPT）
- 星空 + 极光动态背景、入场动画、移动端横滑决策树；`prefers-reduced-motion` 自动降级

## 文件结构

```
index.html        平行人生：页面结构与样式（呈现组）
data.js           平行人生：剧本/事件/属性/版本号（内容组）
engine.js         平行人生：推演/评分/渲染/导出（技术组）

life.html         人生无限分岔：页面结构与样式（呈现组）
life_data.js      人生无限分岔：家庭/节点/事件/结局（内容组）
life_engine.js    人生无限分岔：宿命/回响/结局/存档（技术组）

README_先看这个.md  三人分工与 14 天执行表（先读这个）
CHANGELOG.md      版本更新日志
分工方案.md        早期 React 方案草案（已不适用）
跟AI怎么说.md      早期 React 方案提示词（已不适用）
```

**一人一文件，别两个人同时改同一个文件。** 版本号与更新日志统一在 `data.js`（`life.html` 只读这两个字段）。

## 版本

当前 **v2.1.0**（2026-11-17）。版本号遵循 semver：玩法/结构大改 → 主版本；新剧本/新功能 → 次版本；文案/数值/修 bug → 修订号。
每次更新两处一起改：`data.js` 的 `version` + `changelog`，以及根目录 `CHANGELOG.md`。

## 答辩口径（别硬吹）

- 这是**情景推演，不是对真实未来的预测**（页脚与说明里都写了免责声明）。
- 技术上是**规则系统 + 随机事件 + 文案**，完全离线；没有调用大模型 API。
- AI 部分是可插拔的：未来接大模型只需要替换 `engine.js` 里的 `adjustRate / calcScore / makeEvent` 与文案生成。
