# 世界规则修改器

选一条现实规则，调四个参数，设三个世界假设，生成一条从原始到现代的长河。两页式：第 1 页设定，第 2 页只读长河——5 个时代、15 件大事，每件对照「原来 / 现在 / 为什么」，被规则改写的盖深红「已改写」章。

在线体验：https://fang3333.github.io/dad-and-son/

情景推演，不是史实，也不是对真实未来的预测。

## 怎么玩

1. 第 1 页「设定」：选一条规则（取消大学考试 / 每天只工作四小时 / 商品不再有价格），拨四个参数开关，再设三个世界假设（技术会继续累积 / 资源足够 / 群体愿意合作）。点蓝色「生成这个世界 →」。
2. 第 2 页「长河」只读：原始 / 古代 / 近代早期 / 工业 / 现代五个时代，每时代 3 件大事。每件卡固定三段——原来怎样、现在怎样、为什么；点「+ 连锁反应」看它对下一时代的影响。被改写的卡深红左边线 + 「已改写」章，没改的灰线 + 「未改写」章。热点（亮哥的头发 / 不烧心）混在现代里，带代号和「虚构」章。
3. 顶栏常驻世界名 + 第 N 版 + 规则/参数/假设摘要；点蓝色「修改假设」回第 1 页，选择原样保留，再次生成版本 +1。刷新不丢。
4. 假设不是装饰：关掉「资源足够」，免费世界的改写会整段落空，卡上写明原因；拨参数也会换讲法（比如允许黑市后，货币不是消失而是转进巷子）。

## 打开方式

- 双击 index.html 即可（file:// 直开）。
- 或任意静态服务器，例如 `npx serve` / `python -m http.server`。
- 断网可玩。无框架、无 CDN、无外部图片、无构建步骤。

## 三条诚实约定

- 长河是情景推演：每件大事的「现在」是按规则、参数、假设推出来的对照线，不是史实，也不是预测；卡上带「推算 / 假设 / 不确定」标签。
- 改写判定可追溯：每张卡的「为什么」一句话指回规则、参数或假设；假设关闭时改写落空，页面直说，不假装改写了。
- 热点只用代号、只写公开现象的虚构改写（亮哥 / 不烧心），每张带「虚构」章与「勿对号入座」注记，不写真实人物私生活。
