# 世界规则修改器

选一套本地剧本，调四个参数、三个世界假设和科幻机制，生成从原始到 2200 后人类的八版报纸。每版五张改写卡：三件世界大事，两件成年人的学习与恋爱小事。也可以填自己的 API Key，写自定义规则，由 AI 生成同样结构的报纸。

在线体验：https://fang3333.github.io/dad-and-son/

情景推演，不是史实，也不是对真实未来的预测。八版个人线是不同年代的独立人生切片。

## 怎么玩

1. 设定页有三条快捷规则、十八套剧本库和自定义入口。剧本库包含取消考试、四小时工作制、商品免费、太阳熄灭、智子锁死、黑暗森林、降维打击、记忆继承、时间加速、重力减半、全民长生、语言消失、月球坠落、全球断网、植物会说话、每人只能活 30 年、国界消失、考试变直播。「随机一组」载入另一套默认设定，不会立即生成。
2. 调四个规则参数与三个世界假设：技术会继续累积、资源足够、群体愿意合作。关闭假设会改变执行成本、学习办法或办理条件，不把卡片全部清空。
3. 可叠加三体机制与电影机制，两组共十二项，合计最多三项。这里只借时间差、资源预算等机制，不复述影视人物、台词和情节；矛盾组合会阻止生成并说明原因。
4. 八个干预时代依次是原始、古代、近代早期、工业、现代、2050、2100、2200 后人类。年份可选填；干预前不生成章节，首个可用版显示干预点与前情。例如选工业，就从第 4 版开始，保留第 4–8 版。
5. 点「生成这个世界」进入本地报纸，不发送 API 请求。每版只读、一屏五卡，世界三件在上，个人两件在下。卡片显示「原来 / 现在」，世界用红章，个人用蓝色「私」章。手机世界卡两列，第三张跨列；个人卡两列。
6. 点卡片打开 80–120 字详情、改写原因与可选连锁；Esc、关闭按钮或遮罩均可退出。底部上一版、版点、下一版以及键盘左右键翻页；末版回到首个可用版。URL 为 `#chapter/1` 至 `#chapter/8`，浏览器前进后退可用。每次生成编号加一，翻页不加；设定保存在本机，刷新后重新生成报纸。
7. 「修改假设」回设定页；「生成海报」打开 1080×1440 纯文字 Canvas 海报，可下载 PNG。海报包含规则、假设、机制、参数、八时代摘要、个人切片和改写印章；干预之前标为未干预，不补造经历。
8. AI 仅用于自定义规则。顶部「API 设置」配置 OpenAI 兼容接口、Key、模型和温度；可刷新模型列表，失败后手填模型。自定义名称、描述与四个参数名填写完整后生成。AI 必须返回干预之后全部章节且每章三世界、两个人，缺章缺卡会明确报错并提供本地剧本入口，不拿旧模板冒充自定义结果。返回设定页后可「重新生成」，强制绕过缓存。

## AI 与 Key

Key 只存在你自己的浏览器里，不上传我们的服务器；但浏览器端调用仍有泄露风险，建议用临时 Key，演示完吊销。

默认存 localStorage，勾「仅本次会话」则存 sessionStorage。Key 不进 URL、海报、日志和错误文案，普通界面只显示后四位掩码；「测试连接」不保存设置。请求从浏览器直达用户配置的服务商，需要服务商支持 CORS。

结果缓存按规则、参数、干预、假设、机制、模型、接口地址和温度区分，最多八条；缓存命中不发生成请求。AI 错误使用静态中文提示，JSON 格式解析失败只重试一次。全部本地剧本与海报不需要 Key，断网仍可玩。

## 打开方式

- 双击 `index.html`（file://）即可。
- 或使用静态服务器，例如 `python -m http.server`。
- 无框架、无 CDN、无外部图片、无构建步骤。

## 诚实约定

- 「原来」是用于比较的简化情境，「现在」与未来都是假设，不编造具体统计数字。
- 默认十八套共 144 章、720 卡；修改参数或机制后的详情说明当前条件，不把模板内容伪装成 AI 输出。
- 个人线只写成年人；不写真实人物私密经历。既有热点代号规则保留，涉及热点的浮层明确标「虚构，勿对号入座」。
- 不复制文学原文、影视台词或具体情节；第三方技能、私人笔记与源材料不随生产站点发布。
