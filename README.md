# 世界规则修改器

选一条现实规则，调四个参数，推演一个虚拟世界：教育、经济、社会、个人四个维度怎么变，因果链怎么连，会出现什么意外后果。再换一组参数生成第二个世界对比，最后出一份报告卡和一张号外海报。

在线体验：https://fang3333.github.io/dad-and-son/

情景推演，不是对真实未来的预测。所有数字为示意，不是统计数据。

## 怎么玩

1. 在规则库选一条规则：取消大学考试 / 每天只工作四小时 / 商品不再有价格。
2. 拨四个参数开关。每个参数下面写着它对指标的权重示意。
3. 点「生成这个世界」。看四维面板、因果图、三条意外后果。
4. 在对比区调世界 B 的参数，或一键载入示例 A/B，点「生成世界 B 并对比」。
5. 看报告卡，点「下载海报 PNG」拿走一张 1080×1440 的世界线号外。
6. 世界页底部有副刊「热点改写」：按分类翻卡，点「收进档案」把最多 3 张贴进报告页的副刊摘录。

AI 叙事是可选开关，默认关。开了也只换讲法，不改指标、事件和因果边；失败自动回退内置文案。

## 打开方式

- 双击 index.html 即可（file:// 直开）。
- 或任意静态服务器，例如 `npx serve` / `python -m http.server`。
- 断网可玩。无框架、无 CDN、无外部图片、无构建步骤。

## 文件

| 文件 | 职责 |
|---|---|
| index.html | 语义骨架与 id 契约 |
| styles.css | B 报纸版式：tokens、栏式、断点、唯一印章动效 |
| app.js | 状态与主交互，接数据与引擎 |
| causal.js | 因果图：桌面 SVG / 手机竖排列表 |
| report.js | 报告卡与解读槽 |
| poster.js | Canvas 海报 1080×1440 导出 |
| ai.js | 可选叙事层，默认关闭 |
| hot-cards.js | 副刊 24 张热点改写卡（代号化，虚构注记） |
| world-rule/data.js | 3 规则 × A/B 预设世界（数据契约，不改结构） |
| world-rule/engine.js | 指标修正与对比引擎（不改） |
| ui-mockups/ | B 方案视觉参考，不参与生产页面 |

## 两条诚实约定

- 指标为 0–100 示意分数，只用于同一规则内 A/B 对比，不跨规则比较。
- 任意参数组合由引擎按最近预设 + 参数权重近似：指标会真变，叙事跟随最近预设。页面用「近似推演」徽章和「较示例」差值把这件事写明，不假装事件被重新生成。
