# 世界规则修改器

如果 3–18 条规则同时发生，从原始开始，世界会怎样？选规则筹码，生成十版报纸，在四处分叉点改走另一条路。每版三件世界大事、两件成年人的个人小事。

在线体验：https://fang3333.github.io/dad-and-son/ （以实际部署为准）

## 怎么玩

1. 主屏只有一句话、规则筹码、开始时代和一个生成按钮。点筹码可替换或删除；「+ 加一条」打开可搜索、按七组分类的规则列表。至少选 3 条，最多 18 条。「洗牌」随机选 3–6 条；「全部规则」确认后进入 18 条混沌模式。
2. 高级设置默认折叠，包含四个共同执行参数、三个世界假设、最多三个科幻机制、API 设置和自定义附加约束。本地组合无需 Key，不发送生成请求。规则矛盾会在卡片盖「冲突」章，详情说明谁压住谁。
3. 十个时代依次是原始、古代、古典、近代早期、工业、电气、现代、2050、2100、2200 后人类。较晚开始时只生成该时代及以后，不编造干预前经历。
4. 每版固定五卡。三张世界卡按制度、技术、文明归并，3 条时每卡一条；18 条时每组 6 条。卡面最多显示 4 个规则标签，其余数量用 +N 表示，详情列全。尚未起作用的规则在详情标 dormant，不另占一张空卡。
5. 个人两卡分别写成年学习、恋爱；现代及以后把工作写进学习卡，不额外增加第六卡。个人线是不同年代的虚构人生切片，不是同一个人活一万年。
6. 原始（1）、工业（5）、2050（8）、2200（10）版底部可分叉。选择新方向后当前章节刷新到新线，前面章节直接复用，只计算当前时代及以后。原线不变；完整分叉组合共 24 种。顶部显示路径，如 `1A-5B-8A-10C`。
7. 最近五条世界线保存在浏览器，顶部文字下拉可切换。新生成或分叉才增加 `WL-003` 编号，翻页不增加。超出五条时最旧记录移出；可先下载海报。刷新恢复最近记录；浏览器禁止存储或容量不足时会提示，仅保留本次会话。
8. 点卡片打开详情、原因与连锁；Esc、关闭按钮或遮罩退出。底部按钮、版点或键盘左右键翻页，URL 为 `#chapter/1` 至 `#chapter/10`。最后一版回到首个可用版。
9. 每版可生成 1080×1440 纯文字 Canvas 海报，含规则筹码、路径、十时代摘要、最离谱改写和你的十版一生；可下载 PNG，无图片服务或外部图片。

## 自定义与 Key

高级里的自定义是叠加到所选规则上的额外约束，不占第十九个筹码。开启后使用用户配置的模型；生成前须填写名称、四个参数名和 Key。AI 失败不会伪造自定义结果，分叉失败也不会覆盖旧线；可关闭自定义后离线生成。

Key 只存在你自己的浏览器里，不上传我们的服务器；但浏览器端调用仍有泄露风险，建议用临时 Key，演示完吊销。

默认存 localStorage，勾「仅本次会话」则存 sessionStorage。Key 不进 URL、海报、日志和错误文案，普通界面仅显示后四位掩码。「测试连接」不保存设置；模型列表失败可手填模型名。浏览器直连服务商，需要 CORS 支持。AI 请求只接收生成所需规则、参数、分叉与前情，不发送 API 设置文本。

缓存区分规则组合、参数、开始时代、假设、机制、完整分叉路径、模型、接口和温度，最多八条。命中不发生成请求；高级里的重新生成可绕过缓存。响应体读取也受超时约束，错误只用静态中文提示，JSON 解析失败重试一次。

## 打开方式

- 双击 `index.html`（file://），或运行 `python -m http.server`。
- 纯 HTML/CSS/JS，经典 defer 脚本，无框架、CDN、外部图片或构建步骤。
- 主屏与章节按 1440×900、390×844 一屏排版；长规则列表和高级内容在自己的面板内滚动。

| chapter.js | 五卡、规则标签、冲突章、详情、路径与切线 |

`window.WRM_RECIPE` 是当前设定，`window.WRM_RUNS` 是最近五条已生成记录。recipe 包含 `rules/startEra/assumptions/branchPath/params/worldAssumptions/custom`。记录包含 `id/parentId/recipe/path/chapters`；章节提供 `worldCards/personalCards/branch`。

历史 `causal.js/report.js/poster.js/hot-cards.js/chain-data.js/river-data.js/river.js/custom-rule.js/functions/` 留库不加载。私人笔记、技能原材料和非 B 方案素材不随生产站点提交。

## 诚实约定

「原来」是简化比较情境；改写、科幻、未来和个人线均为假设，不是史实或预测。本地是确定性规则合并，不冒充 AI。只写成年人，不写真人私密经历；科幻只借机制，不复制影视台词、人物或具体情节。

当前代码 v2.5.0；发布与验证记录见 CHANGELOG.md，线上以实际部署为准。
