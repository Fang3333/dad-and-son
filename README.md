# 世界规则修改器

选一条现实规则，调四个参数，推演一个虚拟世界。结果按「八版报纸」逐版翻开：头版、教育、经济、社会与个人、因果、热点副刊、对比、档案——一次只看一版，点「下一版」或按 → 继续。最后出一份报告卡和一张号外海报。

在线体验：https://fang3333.github.io/dad-and-son/

情景推演，不是对真实未来的预测。所有数字为示意，不是统计数据。

## 怎么玩

1. 点页头蓝色「编辑规则与参数 →」按钮展开编辑台：选一条规则（取消大学考试 / 每天只工作四小时 / 商品不再有价格），拨四个参数开关（每个参数下写着权重示意），点蓝色「生成这个世界」。拨开关或切规则会立即重算并回到头版。
2. 编辑台内「读者来稿 · 自定义规则」区：用一句话写自己想改的规则（≤200 字，附 3 条示例），点「推演这条来稿」，编辑台收起并回到头版。启用 AI 时模型解析成指标修正 + 整版事件 / 维度 / 意外（约 1 次调用）；未启用或失败时关键词近似解析，只路由到最接近的内置规则并明说零调用。「清除来稿，回内置规则」退出自定义模式。
3. 用顶部翻页器（手机在底部固定条）逐版阅读，共 8 版：
   - 第 1 版 头版：世界名 + 4 项指标 + 一句结论。
   - 第 2/3 版 教育 / 经济：各 2 条变化直接显示，不折叠。
   - 第 4 版 社会与个人：左右各 2 条，直接显示。
   - 第 5 版 因果长河：从原始到现代 5 个时代、13 个主线节点、12 条主线边、3 条热点支线。桌面横向时代色带可左右滚，手机竖排时间轴。点节点展开「史实锚点 / 本世界线 / 因果后果」三层；被当前规则/参数改写的节点深红框 + 「已改写」章 + 「改写自 规则 · 参数」行；节点「承」行显示上游因果边；AI 节点通知文案跟随当前世界线版号。下方版本历史条点旧版只读预览，任选两版比指标与改写节点。原「本规则 10 年因果链（6 事件）」收在折叠台里。
   - 第 6 版 热点副刊：按热度固定 3 张 S 级主梗卡（现实线 / 本世界线 / 梗标签 / 热度章 / 梗源出处 / 虚构章），不需再点；点「收进档案」最多收 3 张。
   - 第 7 版 对比：A/B 两栏各 4 指标 + 最多 3 条差异；展开折叠台调世界 B 参数或载入示例。
   - 第 8 版 档案：报告卡 + 副刊摘录 + 方法折叠区，点「下载海报 PNG」拿走 1080×1440 号外。
4. 键盘 ← → 翻页；切版自动回到顶部并把焦点移到本版标题。
5. 世界线修订版号常驻页头与翻页条：规则或参数每改一次 +1（拨回也算一次），引擎修订（应用版本更新）也 +1 并标「引擎修订 vN」，同参数重跑不增版，刷新不丢，历史只留最近 5 版，可一键清空从第 1 版重新编号。自定义来稿走 D 字头（#D-001…），来稿文本不同才 +1。报告卡与海报底部带「世界线 #A-003 · 第 3 版」式编号。

AI 叙事是可选开关，默认关。开了也只换讲法，不改指标、事件和因果边；失败自动回退内置文案。部署在 Qoder Sites 且站长配好 Secret 时优先走公共代理（访客免填 Key，服务端限流 + 缓存）；其余情况第 8 版可自填接口地址与模型（默认阿里云百炼 DashScope OpenAI 兼容端点 · qwen-plus，DeepSeek 等 OpenAI 兼容端点亦可），Key 只存本机 localStorage。自定义来稿共用同一开关与通道：启用时每条来稿约 1 次调用，未启用零调用。

## 打开方式

- 双击 index.html 即可（file:// 直开）。
- 或任意静态服务器，例如 `npx serve` / `python -m http.server`。
- 断网可玩。无框架、无 CDN、无外部图片、无构建步骤。

## 三条诚实约定

- 指标为 0–100 示意分数，只用于同一规则内 A/B 对比，不跨规则比较。
- 任意参数组合由引擎按最近预设 + 参数权重近似：指标会真变，叙事跟随最近预设。页面用「近似推演」徽章和「较示例」差值把这件事写明，不假装事件被重新生成。
- 自定义来稿的指标 = 示例基线 + AI 给的 ±25 以内示意修正，事件与维度整版由 AI 改写，置信度标「低」；未启用 AI 时只路由到内置规则、不改写内容，页面明说「零调用」。
- 副刊只做 S 级国民梗，每张附「梗源」公开出处（source · date · metric）。真实人物只用代号、只写公开职业事件；姬霓、皮衣哥为虚构。梗源指公开现象，改写部分为虚构，勿对号入座。
