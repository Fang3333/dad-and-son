# 世界规则修改器

选一条现实规则，调四个参数，推演一个虚拟世界。结果按「八版报纸」逐版翻开：头版、教育、经济、社会与个人、因果、热点副刊、对比、档案——一次只看一版，点「下一版」或按 → 继续。最后出一份报告卡和一张号外海报。

在线体验：https://fang3333.github.io/dad-and-son/

情景推演，不是对真实未来的预测。所有数字为示意，不是统计数据。

## 怎么玩

1. 点页头「编辑规则与参数」展开编辑台：选一条规则（取消大学考试 / 每天只工作四小时 / 商品不再有价格），拨四个参数开关（每个参数下写着权重示意），点「生成这个世界」。拨开关或切规则会立即重算并回到头版。
2. 用顶部翻页器（手机在底部固定条）逐版阅读，共 8 版：
   - 第 1 版 头版：世界名 + 4 项指标 + 一句结论。
   - 第 2/3 版 教育 / 经济：各看第 1 条变化，第 2 条收在「还有一条」里。
   - 第 4 版 社会与个人：左右各 1 条，各自折叠第 2 条。
   - 第 5 版 因果：默认 3 个关键节点 + 2 条边，点「展开全部 6 节点」看完整链。
   - 第 6 版 热点副刊：一次 2 张 S 级主梗卡（现实线 / 本世界线 / 梗标签 / 梗源出处 / 虚构章），「换一批」轮播，点「收进档案」最多收 3 张。
   - 第 7 版 对比：A/B 两栏各 4 指标 + 最多 3 条差异；展开折叠台调世界 B 参数或载入示例。
   - 第 8 版 档案：报告卡 + 副刊摘录 + 方法折叠区，点「下载海报 PNG」拿走 1080×1440 号外。
3. 键盘 ← → 翻页；切版自动回到顶部并把焦点移到本版标题。

AI 叙事是可选开关，默认关。开了也只换讲法，不改指标、事件和因果边；失败自动回退内置文案。

## 打开方式

- 双击 index.html 即可（file:// 直开）。
- 或任意静态服务器，例如 `npx serve` / `python -m http.server`。
- 断网可玩。无框架、无 CDN、无外部图片、无构建步骤。

## 文件

| 文件 | 职责 |
|---|---|
| index.html | 语义骨架与 id 契约（八版页 + 页头规则条 + 翻页器） |
| styles.css | B 报纸版式：tokens、版页、断点、底部操作条、唯一 180ms 翻页动效 |
| app.js | 八版翻页状态机与主交互，接数据与引擎 |
| causal.js | 因果图：桌面 SVG / 手机竖排列表 |
| report.js | 报告卡与解读槽 |
| poster.js | Canvas 海报 1080×1440 导出 |
| ai.js | 可选叙事层，默认关闭 |
| hot-cards.js | 副刊 12 张 S 级国民梗卡（WRM_HOT_EVENTS，带 heatProof 梗源出处，代号化，虚构注记） |
| world-rule/data.js | 3 规则 × A/B 预设世界（数据契约，不改结构） |
| world-rule/engine.js | 指标修正与对比引擎（不改） |
| ui-mockups/ | B 方案视觉参考，不参与生产页面 |

## 三条诚实约定

- 指标为 0–100 示意分数，只用于同一规则内 A/B 对比，不跨规则比较。
- 任意参数组合由引擎按最近预设 + 参数权重近似：指标会真变，叙事跟随最近预设。页面用「近似推演」徽章和「较示例」差值把这件事写明，不假装事件被重新生成。
- 副刊只做 S 级国民梗，每张附「梗源」公开出处（source · date · metric）。真实人物只用代号、只写公开职业事件；姬霓、皮衣哥为虚构。梗源指公开现象，改写部分为虚构，勿对号入座。
